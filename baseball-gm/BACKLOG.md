# 남은 과제 (BACKLOG)

작업할 때마다 갱신한다. 위에 있을수록 우선순위가 높다.
각 항목은 **무엇이 문제인지 → 왜 중요한지 → 결정이 필요한 것**을 적는다.
매 작업 후 `node tools/balance-check.js` (실제 엔진 8시즌)를 돌려 결과를 확인한다. 게임 안에서는 헤더의 "8시즌 밸런스 진단" 버튼.

## 🔴 결정 필요 (사용자 판단)

1. **직접 플레이 피드백** — 새 화면 구조(6개 영역 · 단장실 · 정보 유형 배지)로 한 시즌을 돌려 보고, 어디서 헷갈리는지 알려주기.
2. **'비서 추천' 맡기기 버튼의 위치** — 지금은 결정 대기함에서 원클릭으로 비서에게 맡길 수 있다. 편하지만 '단장이 직접 판단한다'는 몰입을 줄일 수 있다. 유지 / 난이도 '어려움'에서만 숨김 / 제거 중 선택.

## 🟡 개선 후보

- **디자인 2차 (남은 시각 개선)** — 화면 안쪽 본문에 인라인 스타일이 많이 남아 있다(약 360곳). 표 숫자 열 우측 정렬, 로스터 '주요 기록' 열 분해(투수/타자), 행마다 버튼 4개 → '⋯' 메뉴, 이모지 아이콘 → 라인 아이콘, 선수 상세 모달에 추정 범위·계약 정보 정리, 스토브리그 단계(열림/예정/마감) 표시.

4. **'보통' 난이도 체감 검증** — 게임이 어느 정도 잡히면 직접 플레이로 확인하기로 함.
5. **트레이드 장부 과소 집계** — 보낸 선수가 KBO를 떠나면(방출·은퇴·MLB) 이후 기록이 사라져 손실이 적게 잡힌다.
6. **구단주 증액 효과의 귀속** — '증액 이후 영입한 선수의 WAR'로 계산해 인과가 느슨하다.
7. **비FA 다년계약 후속** — FA 등급 산정 시 비FA 연봉 제외 규정, 다년계약 선수의 보호명단 처리, 방출 선수(자유계약) 계약금 예외는 아직 없음.
8. **기존 FA 계약 연수 카운트** — FA 계약(예: 4년)이 실제로는 3시즌 뒤 다시 FA가 되는 off-by-one이 있어 보인다(비FA 다년계약은 보정함). 확인 후 수정.

## ✅ 결정 완료 (변경하지 않음)

- 경쟁균형세 제재율은 현행(1회 50% · 2회 연속 100% + 1R 9단계 · 3회 150%) 유지.
- 최하위 팀 보정 없음 (a: 그대로).
- 위임 지명은 단장이 방침(육성 방향·출신·포지션 우선순위)만 정한다.

- 첫 시즌 전력 격차 유지 — 팀 선택이 곧 '왕조 유지 vs 왕조 만들기' 난이도.
- 역순 모기업 지원금 유지 — 난이도 조절 수단.
- 포스트시즌 배당금(최대 50억) 유지 — 현실 반영 우선.
- 방치한 유저 구단의 적자 유지 — 적자 → 신임도 하락 → 재계약 불리.
- 위임 지명은 번복 불가.
