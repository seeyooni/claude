# 남은 과제 (BACKLOG)

작업할 때마다 갱신한다. 위에 있을수록 우선순위가 높다.
각 항목은 **무엇이 문제인지 → 왜 중요한지 → 결정이 필요한 것**을 적는다.
매 작업 후 `node tools/balance-check.js` (실제 엔진 8시즌 × 3회)를 돌려 결과를 확인한다. 게임 안에서는 헤더의 "8시즌 밸런스 진단" 버튼.

## 🔴 결정 필요 (사용자 판단)

1. **신인 드래프트 운영 방식** — 단장 직접 지명 / 스카우트팀 위임 / 혼합. 청소년 국가대표 경기 직관은 필수. (설계안은 대화에서 제안, 결정 대기)

2. **슈퍼스타 증가 후 8년차 전력 평준화 약화**
   - 현상: 성장 상향(보통 기준) 후 8년차 승률 SD 0.096 · 1위 .660 · 10위 .351 (7년차까지는 0.067~0.079). 90+ 선수가 12명까지 늘며 아직 안정되지 않음.
   - 추정 원인: 슈퍼스타 재목이 특정 구단에 몰림 (드래프트 상위 지명 + 장기 보유). 3회 평균이라 노이즈일 수도 있어 추가 측정 필요.
   - 선택지: (a) 그대로 (왕조의 탄생) (b) 슈퍼스타 FA·포스팅 이탈 압력 강화 (c) 90+ 선수 연봉 상승으로 자연 분산.

## 🟡 개선 후보 (구현 가능, 우선순위 미정)

3. **'보통' 난이도 체감 검증** — 게임이 어느 정도 잡히면 직접 플레이로 확인하기로 함.
4. **트레이드 장부의 한계** — 보낸 선수가 KBO를 떠나면(방출·은퇴·MLB) 이후 기록이 사라져 손실이 과소 집계된다. 트레이드 연도는 시즌 전체 WAR로 계산(트레이드 이전 경기 포함).
5. **구단주 증액 효과의 귀속** — 지금은 '증액 승인 이후 영입한 선수의 WAR'로 계산해 인과가 느슨하다(어차피 했을 영입도 포함). 증액 금액으로 산 영입을 명시적으로 묶는 방식 검토.
6. **유망주 잠재력 정보 노출** — 유저 구단의 드래프트 추천 점수가 실제 잠재력을 거의 그대로 사용해 Fog of War가 약하다. 드래프트 설계와 함께 손볼 것.

## ✅ 결정 완료 (변경하지 않음)

- 첫 시즌 전력 격차 유지 — 팀 선택 자체가 '왕조 유지 vs 왕조 만들기' 난이도 선택.
- 역순 모기업 지원금 유지 — 현실과 다르지만 난이도 조절 수단.
- 포스트시즌 배당금(최대 50억) 유지 — 현실 반영 우선.
- 방치한 유저 구단의 적자 유지 — 적자 → 신임도 하락 → 재계약 불리. 방치하면 벌을 받는 구조.

## ✅ 최근 완료

- 난이도별 성장 환경 (7년차 95+: 쉬움 4.0 · 보통 2.2 · 어려움 0.9명), 잠재력 97+ 슈퍼스타 재목 가속.
- 게임 내 "8시즌 밸런스 진단" 버튼 (진행률·취소, 진행 중인 게임 영향 없음, 약 3초/회).
- 시즌 회고 리포트 확장: 트레이드 장부(누적), 드래프트 연도별 성과, 구단주 증액 효과.
- 1,000회 진단 16개 항목.
