# 남은 과제 (BACKLOG)

작업할 때마다 갱신한다. 위에 있을수록 우선순위가 높다.
각 항목은 **무엇이 문제인지 → 왜 중요한지 → 결정이 필요한 것**을 적는다.

## 🔴 결정 필요 (사용자 판단)

1. **첫 시즌 전력 격차가 실제보다 크다**
   - 현상: 2025 시즌 KIA 승률 .680~.720, 최하위 .30대. 실제 2024 KBO는 .613~.403.
   - 원인: 2024 체급(78 vs 67)이 승률로 바뀌는 강도가 너무 셈 (평준화 제도가 아니라 경기 시뮬 보정 문제).
   - 선택지: (a) 체급 간격을 줄여 첫해부터 현실적으로 (b) 유지해 "꼴찌 팀 뒤집기"의 첫해 난이도 보존.

2. **포스팅 기준 수치**
   - 현재: 11/1~12/15, OVR 82+ 또는 단일 능력치 89+, 만 31세 이하, 구단당 최대 1명.
   - 이 게임의 OVR 상한이 실질적으로 83~84라서 요청하신 'OVR 90 / 능력치 95'는 영원히 도달 불가 → 같은 희소성(리그 상위 약 1%)으로 맞춤.
   - 확인 필요: 실제 KBO처럼 **7시즌 이상 뛴 선수만** 포스팅 가능하게 할지.

3. **역순 지원금 vs 현실의 모기업**
   - 현실의 모기업은 성적이 나쁘면 지원을 줄이는 경우가 많다. 게임적 재미를 위한 의도된 이탈로 둘지, 구단주 성향(명문/가성비/리빌딩)별로 지원 방식을 다르게 할지.

4. **'보통' 난이도의 빡빡함 체감 검증**
   - 시뮬레이션의 단장은 아무것도 안 하므로, 적극적으로 FA를 잡는 플레이어가 실제로 증액 요청까지 몰리는지는 직접 플레이로만 확인 가능. 체감 후 배율(1위 1.20 ~ 10위 1.65, 이월 상한 20억) 조정.

## 🟡 개선 후보 (구현 가능, 우선순위 미정)

5. **OVR 스케일 자체가 낮게 눌려 있음** — 최고 OVR 83~84, 4시즌 동안 85+ 선수가 한 명도 안 나옴. 성장 상한(잠재력)·노쇠화 공식을 점검하면 "슈퍼스타"가 탄생하는 서사가 생긴다. 1·2번 과제와 연결됨.
6. **시즌 결산 회고 리포트** — 평준화가 강해질수록 성적이 '단장의 결정' 덕인지 '제도의 순환' 덕인지 구분하기 어렵다. 시즌 말 "이번 시즌 결정이 승수에 미친 영향" 리포트.
7. **포스트시즌 배당금(최대 50억)** — 우승팀을 부자로 만드는 반평준화 요소. 현재는 실제 제도라 유지, 이월 상한이 대부분 걸러냄.
8. **1,000회 진단의 경기 결과는 간이 연산** — 기능 발동 여부만 검증하고 밸런스는 못 본다. 실제 엔진으로 몇 시즌을 돌려 승률 분산·순위 상관·재정 범위를 검사하는 "밸런스 진단" 버튼 추가 검토.

## ✅ 최근 완료

- 상무: 초기 병역 상태를 나이로 배정(25세+ 군필, 21~24세 무작위, 20세 이하 미필), 유저 구단 12월 자동 입대 제외, 복무 한도 4명 통일.
- 포스팅: 리그 최정상급만, 포스팅 기간에만, 구단당 1명, 불허 반복 방지, 미자격 선수 포스팅 차단.
- FA: 원소속 우선협상 7일 후 자동으로 타 구단 FA 공개, 기간 중 입찰 마감 차단, 매년 우선협상 기간이 새로 열리도록 수정.
- 재정 개편·난이도·전력 평준화 (이전 작업).
