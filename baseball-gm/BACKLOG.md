# 남은 과제 (BACKLOG)

작업할 때마다 갱신한다. 위에 있을수록 우선순위가 높다.
각 항목은 **무엇이 문제인지 → 왜 중요한지 → 결정이 필요한 것**을 적는다.
매 작업 후 `node tools/balance-check.js` (실제 엔진 8시즌 × 3회)를 돌려 결과를 확인한다.

## 🔴 결정 필요 (사용자 판단)

1. **OVR 95가 나오는 빈도**
   - 현재: 8시즌 동안 95+ 0명, 12시즌 돌리면 7년차쯤 1명 등장 (2회 중 1회). 90+는 8년차에 리그 3~8명.
   - "가끔 95"의 기준이 '단장 한 명의 재임 기간(3~6년) 안에 한 번쯤'이라면 성장률을 조금 더 올려야 한다. 대신 90+ 인원도 함께 늘어난다.

2. **아무 조작도 안 하는 유저 구단의 적자** (직접 플레이 시 체감 확인 필요)
   - 현상: 12/1 연봉 재계약 자동 처리가 여유 예산을 보지 않고 '적정 협상'으로 일괄 체결 → 방치한 유저 구단이 −50~−110억까지 적자.
   - AI 구단은 대체로 0 근처를 유지. 실제 플레이에서는 단장이 직접 처리하므로 문제가 안 될 수 있다.
   - 선택지: (a) 그대로 (방치하면 벌을 받는 게 맞다) (b) 자동 처리 시 여유 예산에 맞춰 '긴축 협상'으로 전환.

## 🟡 개선 후보 (구현 가능, 우선순위 미정)

3. **'보통' 난이도 체감 검증** — 구성이 갖춰지면 직접 플레이로 확인하기로 함. 배율(1위 1.20 ~ 10위 1.65, 이월 상한 20억) 조정 대기.
4. **시즌 회고 리포트 확장** — 현재는 영입/이탈 WAR, 성장, 운, 재정. 다음 후보: 트레이드별 손익표(보낸 선수 vs 받은 선수 WAR 누적), 드래프트 지명의 장기 성과(몇 년 뒤 WAR), 구단주 증액 요청이 승수로 이어졌는지.
5. **게임 내 '밸런스 진단' 버튼** — 지금은 개발용 `tools/balance-check.js`로만 실행. 브라우저에서 8시즌을 돌리면 약 2~5분 걸리므로, 넣는다면 진행률 표시와 함께 비동기로.

## ✅ 결정 완료 (변경하지 않음)

- 첫 시즌 전력 격차 유지 — 팀 선택 자체가 '왕조 유지 vs 왕조 만들기' 난이도 선택.
- 역순 모기업 지원금 유지 — 현실과 다르지만 난이도 조절 수단.
- 포스트시즌 배당금(최대 50억) 유지 — 현실 반영 우선.
