# 남은 과제 (BACKLOG)

작업할 때마다 갱신한다. 위에 있을수록 우선순위가 높다.
각 항목은 **무엇이 문제인지 → 왜 중요한지 → 결정이 필요한 것**을 적는다.
매 작업 후 `node tools/balance-check.js` (실제 엔진 8시즌)를 돌려 결과를 확인한다. 게임 안에서는 헤더의 "8시즌 밸런스 진단" 버튼.

## 🔴 결정 필요 (사용자 판단)

1. **직접 플레이 피드백** — 튜토리얼 → 한 시즌 진행. 어디서 헷갈렸는지, '보통' 난이도 체감은 어떤지.
2. **'비서에게 맡기기' 버튼** — (a) 유지 (b) 어려움에서만 숨김 (c) 제거.

## 🟡 개선 후보

1. **간헐적 화면 오류 1건** — 버튼 전수 점검 중 한 번 'null 의 name 을 읽을 수 없음'이 났고 이후 재현되지 않았다. 이제 화면 오류가 나면 알림함에 날짜·화면·코드 위치가 기록되므로, 플레이 중 나오면 그 알림 내용을 알려주면 바로 추적할 수 있다.
2. **튜토리얼 2단계** — 지금은 단장실 화면 안내. 첫 스토브리그 업무(연봉·FA·외국인)를 직접 해 보는 '따라 하기' 단계는 아직 없다.

## ✅ 결정 완료 (변경하지 않음)

- 2차 드래프트 보호: 실제 KBO 규정(2025 개정)을 따른다 — 비FA 다년계약 선수는 자동 보호 아님.

- 경쟁균형세 제재율은 현행(1회 50% · 2회 연속 100% + 1R 9단계 · 3회 150%) 유지.
- 최하위 팀 보정 없음 (a: 그대로).
- 위임 지명은 단장이 방침(육성 방향·출신·포지션 우선순위)만 정한다.

- 첫 시즌 전력 격차 유지 — 팀 선택이 곧 '왕조 유지 vs 왕조 만들기' 난이도.
- 역순 모기업 지원금 유지 — 난이도 조절 수단.
- 포스트시즌 배당금(최대 50억) 유지 — 현실 반영 우선.
- 방치한 유저 구단의 적자 유지 — 적자 → 신임도 하락 → 재계약 불리.
- 위임 지명은 번복 불가.

## ✅ 최근 완료

- 단장실 재구성: '결정 대기함(한 번 처리하면 끝나는 일)' · '비서 추천(의견)' · '계속 지켜볼 지표(매일 바뀌는 상태)'로 나눔. 보호명단 '필수'는 실제로 쓰이는 시기(2차 드래프트 11/1~14, FA 시장 12/1~1/15)에만.
- 비서 추천 순환: 2주 보류 버튼, 화면에 21일 넘게 떠 있던 추천은 14일 쉬고 기다리던 추천이 올라옴, 한 번에 2개 + 시기별 조언 1개(월마다 바뀜).
- 튜토리얼: 새 단장 부임 직후 11단계 안내(화면 강조 + 설명, 키보드 ←/→/Esc), ⚙ 메뉴에서 다시 보기.
- 전력 평준화 재확인: 8회 반복 시 4~8년차 승률 표준편차 평균 약 .071 → 실제 범위. 지난번 .043은 3회 평균의 우연한 편차로 판단, 조정 안 함.
- 2차 드래프트: 상무 복무 중 선수도 지명 대상(보호명단에 넣어야 보호). 지명되면 남은 복무를 새 구단 소속으로 마치고 복귀. AI는 남은 복무 기간만큼 가치를 깎아 지명.
- 화면 오류 기록 장치(알림함), 모바일 화면 가로 넘침 수정.

- 방치 시 적자 폭: 원인은 유저 구단 외국인 선수가 방치되면 시장 권장액(매년 약 +45%, 복리)으로 자동 재계약되던 버그. AI와 같은 성과 연동 인상률(5~35%)로 고침. 방치 시 8년차 여유 예산 −200억 → 쉬움 +24억 · 보통 +69억 · 어려움 +26억(중간에 소폭 적자). 방치의 대가는 이제 '파산'이 아니라 '순위 하락'으로 나타난다.
- 디자인 3차: FA 패널이 기간 밖에는 'FA 시장 닫힘 · 다음 공시 D-n'을 보여주고 공시·마감 버튼을 잠근다(공시는 11/5~ 스토브리그부터 가능). 지난 협상 내역은 '지난 겨울'로 표시. 드래프트 표는 행을 누르면 리포트, 버튼은 지명 가능할 때만.
- 2차 드래프트 자동 보호를 실제 규정에 맞춤: 비FA 다년계약 자동 보호 제거, 신인 1~3년차, 군보류 이력 4년차 추가.
- '새 시즌 개막' 버튼 버그: 1~3월에 누르면 한 시즌을 통째로 건너뛰던 문제 → 일간 엔진으로 3/22 개막일까지 진행(스토브리그 마감 자동 처리 포함).

- 전체 기능 점검: 로스터 행 버튼(1군 콜업·2군행·육성군·상무 입대·방출)이 원본부터 전혀 작동하지 않던 버그 수정(칸에 걸린 클릭 차단 + 행 전체 '선수 상세' 열기가 버튼보다 먼저 처리됨). 2군 육성 과제에서 투수에게 타자 과제가 보이던 문제 수정(+엔진에서도 거부). 실제 클릭 점검 결과 버튼 180종 전부 반응, 팝업·메뉴·상단·저장/불러오기·로비 정상.

- 디자인 2차: 표 숫자 열 우측 정렬(자동), 로스터 기록을 투수(경기·이닝·ERA·승-패-세)/타자(경기·타율·홈런·OPS) 열로 분리하고 그룹 머리글, 행 동작 1개 + '더보기' 메뉴(방출은 메뉴 안), 장식 이모지 약 200개 제거, 선수 상세 창을 평가(확정/추정)·이번 시즌·계약·세부 능력치·지난 시즌으로 정리, 스토브리그 단계 표시(진행 중/예정/완료/마감, 누르면 해당 화면).
- 트레이드 장부: 리그를 떠난 선수의 기록 보존(warBook).
- 구단주 증액 효과: '실제로 필요했던 증액'만큼만 귀속.
- 비FA 후속: FA 등급 순위에서 비FA 연봉 제외, 2차 드래프트 자동 보호, 자유계약(방출) 선수 시장과 계약금 예외.
- FA 계약 연수 off-by-one 수정(4년 계약이 3시즌 뒤 FA가 되던 문제).
- 단일 HTML 빌드(`tools/build-standalone.js` → `dist/kbo-gm.html`), 게임 안 내려받기 버튼이 '병합 중'에 멈춰 있던 문제 수정.

- 디자인 전면 개편: 6개 업무 영역 + ⚙ 메뉴, 상태 바(다음 마감 D-n), 단장실(결정 대기함·받은 보고·마감 60일·팀 현황), 정보 유형 배지, 디자인 토큰(대비 AA), 모달·키보드 접근성, 알림함, 방출·삭제 확인. 겹치던 프런트 심화 섹션 7개 정리. 스카우트 후보 카드에 실제 OVR이 노출되던 문제와 2군 성장 소식 'undefined' 표기 수정.

- 유망주 잠재력 Fog of War: 스카우트 품질(레벨·조사도·직관)에 따라 정확도 (레벨1 평균 오차 6.8, 레벨5+조사 0.7).
- 슈퍼스타 분산: OVR 88+ 연봉/FA 프리미엄, 90+ 잔류 확률 감소, AI 포스팅, 포스팅 불허 시 시장 평가 욕구.
- 신인 드래프트: 1~3R 단장 차례에서 직접 지명, 4~10R 스카우트팀 위임, 9/30 마감. 청소년 국가대표 직관 연 3회. (주간 시뮬이 드래프트를 자동 진행해 직접 지명이 불가능하던 버그 수정)
- 비FA 다년계약 전면 개편 (gm-nonfa.js).
- 1,000회 진단 17개 항목.
