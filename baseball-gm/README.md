# 나만의 야구 단장 만들기 (KBO 단장 모드 v1.0)

브라우저에서 실행되는 KBO 구단 단장 시뮬레이션. 빌드 과정 없이 정적 파일만으로 동작한다.

## 실행

```bash
cd baseball-gm
python3 -m http.server 8000   # http://localhost:8000
```

`index.html`을 파일로 직접 열어도 실행된다. 단, "단일 index.html 다운로드" 버튼은 각 모듈을 `fetch`로 읽기 때문에 웹 서버로 띄웠을 때만 동작한다.

## 재정 모델 (`gm-economy.js`)

단위는 만원(10,000 = 1억).

- **예산 = 한 해 운영 봉투.** 연봉총액이 봉투를 차지하고, `여유 예산 = 예산 − 연봉총액`. FA 계약금·첫해 연봉·시설·구장 개조·현금 트레이드 등 재량 지출은 여유 예산 안에서만 가능하다 (AI 구단도 동일).
- **새 시즌 예산 = 모기업 지원금 + 이월금.**
  - 모기업 지원금 = 리그 평균 연봉총액 × 순위 배율 (직전 정규시즌 1위 1.20 → 10위 1.65, 역순 지급).
  - 이월금 = 시즌 장부 마감(포스트시즌 종료) 시점의 여유 예산을 난이도별 상한 / −30억 하한으로 자른 값에서, 마감 이후 스토브리그 현금 지출을 뺀 금액.
- **정규시즌 주간 정산:** 자체 수입(2,600 + 팬심×22 + 주간 승수×150) − 운영비 3,300. 적자 상태로 정산을 맞으면 유저 구단은 구단주 신임도 하락.
- **방출:** 연봉이 연봉총액에서 빠질 뿐 현금 환급은 없다.

### 난이도 (유저 구단에만 적용, AI는 항상 보통)

| | 지원금 | 초기 예산 | 주간 수입 | 증액 요청 승인 | 적자 시 신임도 | 흑자 이월 상한 |
|---|---|---|---|---|---|---|
| 쉬움 | +15억 | +10억 | ×1.25 | +15%p | 0 | 40억 |
| 보통 | 0 | 0 | ×1.0 | 0 | −1/주 | 20억 |
| 어려움 | −10억 | −8억 | ×0.8 | −12%p | −2/주 | 10억 |

## 전력 평준화 제도

- 신인 드래프트·2차 드래프트·외국인 선수 영입: 직전 순위 역순.
- 경쟁균형세: 상한 = 10개 구단 상위 40인 국내 연봉 평균 × 120%. 1회 초과 50%, 2회 연속 100% + 다음 1R 지명권 9단계 하락, 3회 이상 연속 150% + 9단계 하락 (12월 10일 심사).
- 스토브리그 마감일 자동 처리 (유저가 먼저 처리한 단계는 건너뜀): 12/1 연봉 재계약·FA 공시, 1/15 FA 시장 마감, 1/31 외국인 계약.
- FA 원소속구단 우선협상: 공시 후 7일. 기간 중에는 타 구단 FA가 비공개이고, 종료일에 자동으로 전 구단 자유협상이 열린다.

## 상무 · 포스팅

- 상무: 게임 시작 시 국내 선수 병역 배정 — 만 25세 이상 군필, 21~24세는 나이에 비례한 무작위(21세 20% ~ 24세 80% 군필), 20세 이하 미필. 구단당 동시 복무 4명. 12월 10일 정기 자동 입대는 AI 구단만 (유저 구단은 직접 결정).
- MLB 포스팅: 11월 1일~12월 15일에만, KBO 7시즌 이상 · 만 31세 이하 · 종합 OVR 90+ 또는 단일 능력치 95+ 국내 선수 중 구단당 1명에게 제안. 불허하면 그해에는 재제안 없음.

## 선수 성장 (`Player.applyYearlyDevelopment`, 튜닝 값은 `gm-schema.js`의 `GROWTH`)

매 시즌 종료 후(노쇠화 전) 성장: `(잠재력 − OVR) × 나이별 성장률 × 출전 보정 × 무작위`. 나이별 성장률 21세 이하 0.15 · 24세 이하 0.12 · 27세 이하 0.07 · 30세 이하 0.03. 1군 주전 ×1.25. 각성(6~9%) ×2, 정체(7%) 0. OVR 88 이상은 성장 ×0.4.

## 시즌 회고 리포트 (`gm-retro.js`)

매년 11월 4일 자동 작성 (데이터 기록실 › 시즌 회고 리포트). 직전 시즌 종료 시점 로스터와 비교해 영입 선수 WAR − 이탈 선수 WAR = 결정 순효과(1 WAR ≈ 1승), 득실점 기대 승수 대비 실제 승수(운), 잔류 선수 OVR 변화, 재정을 보여준다. 영입 경로는 선수가 이동할 때 `acquiredVia`로 기록한다.

## 밸런스 진단 (`tools/balance-check.js`)

```bash
node tools/balance-check.js --seasons 8 --runs 3 --team KIA --difficulty NORMAL
```

실제 엔진으로 여러 시즌을 돌려(유저 구단은 아무 조작 없음) 승률 분산·순위 상관·재정·OVR 분포·FA 이적·포스팅을 표로 출력한다. 8시즌 × 3회 약 10초.

남은 과제와 결정이 필요한 사항은 [`BACKLOG.md`](BACKLOG.md)에 정리한다.

## 1,000회 진단 (`KBO_GM.Auditor.runWiringAudit1000`)

헤더의 "1,000회 진단" 버튼. 고속 모드로 1,000시즌을 돌리며 핵심 메카닉이 실제로 발동하는지 검사한다 (경기 결과 자체는 간이 연산, 밸런스는 `tools/balance-check.js`로 확인). 16개 어설션: 기존 6개 + 주간 재정 정산, 지원금 역순, 예산 범위, 경쟁균형세 2회 연속 제재, 1R 9단계 하락, 방출 환급 없음, 스토브리그 자동 처리, 포스팅 7시즌 요건, 연간 성장, 시즌 회고 분류.
